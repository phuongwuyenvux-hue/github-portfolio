# Python Projects Portfolio

A collection of Python utilities and modular applications built for data processing, volume unit conversion, and financial analytics.

### 1. Liquid Unit Converter
A lightweight conversion utility mapping volume measurements between Metric and US Customary systems.
* **File**: `unit-converter.py`
* **Tests**: `test-unit-converter.py`
* **Features**: Converts Liters, Quarts, Fluid Ounces, and Pints with precise float handling.


### 2. Business Expense Tracker
A financial calculator for calculating shop operations, revenue, expenses, and net profit/loss.
* **File**: `business_expense_tracker.py`
* **Features**: Interactive terminal interface processing fixed rental, utility, labor, and inventory costs.
