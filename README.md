# Liquid Unit Converter

A lightweight Python module for converting liquid volume measurements between Metric and US Customary units.

## Features
- **Liters**: Converts to Quarts, Fluid Ounces, and Pints.
- **Quarts**: Converts to Pints, Fluid Ounces, and Liters.
- **Fluid Ounces**: Converts to Pints, Quarts, and Liters.
- **Pints**: Converts to Quarts, Fluid Ounces, and Liters.

## Project Structure
- `unit-converter.py`: Core conversion functions and execution script.
- `README.md`: Project documentation and usage guide.

## Usage
Run the script directly using Python 3:

```bash
python unit-converter.py
